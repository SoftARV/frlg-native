# Frames the golden harness captures and compares.
#
# This file is committed; the images are not. They are frames of a copyrighted
# ROM and this project ships no game data, so each machine blesses its own --
# see docs/adr/0010-goldens-are-generated.md.
#
# tolerance  largest per-channel difference absorbed as harmless
# budget     how many pixels may differ beyond that before the frame fails
# reference  the mGBA frame of the reference ROM showing the same moment, or
#            `-` where our pacing has drifted too far for one to exist
#
# The reference numbers run ahead of ours by 38: mGBA boots through the BIOS and
# the ROM's crt0, where the port enters AgbMain directly. At that offset the two
# settled screens match mGBA pixel for pixel, which is what makes them an oracle
# rather than a regression net.
#
# Frames 400 and 900 have no reference because scene pacing diverges wherever
# the game waits on the audio subsystem, which is stubbed until phase 4. Their
# backgrounds match mGBA exactly; only animated sprites sit at a different phase,
# and no single offset aligns them. See docs/spikes/0004-mgba-frame-alignment.md.
#
# Both thresholds are zero because the renderer is software and deterministic:
# it reproduces a frame exactly, so anything differing at all is a real change.
#
# frame  tolerance  budget  reference  name
100      0          0       138        copyright text on black
400      0          0       -          game freak logo, blending
900      0          0       -          intro cinematic, objects and windows
2400     0          0       2438       title screen
